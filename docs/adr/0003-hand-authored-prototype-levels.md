# Hand-author the first 5 levels; defer the Unity-scene converter

The 75 original levels live as parseable YAML in `rebounder-unity-reference/Assets/Scenes/Levels/**/*.unity` (confirmed: plain text, `Transform`/`MonoBehaviour` blocks readable), so a script to convert all of them to this project's level JSON is possible later. For the prototype we're hand-authoring 5 levels directly in the target JSON shape instead of building that converter first — the level *format* isn't proven yet, and building an extraction pipeline for a schema that might still change is wasted work. The 5 chosen (`Scene1`, `UseTheObstacle`, `FirstTeleporter`, `FirstColourChanger`, `FirstColouredLine`) mirror the original curriculum's own "one new mechanic per level" onboarding order in `LevelOrderHelper.cs`. The converter script, and running it across the remaining ~70 levels, is required work before this can be considered a full port — see `ROADMAP.md`.
